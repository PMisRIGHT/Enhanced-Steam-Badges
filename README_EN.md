# Enhanced Steam Badges
&nbsp;&nbsp;&nbsp;&nbsp;[中文说明](https://github.com/PMisRIGHT/Enhanced-Steam-Badges)
&nbsp;&nbsp;&nbsp;&nbsp;Just a copy-paste-coding Steam badge viewer script

![usage](https://user-images.githubusercontent.com/45200086/209783115-8d20314e-d8c5-4f5e-a6d6-8321714f711e.gif)


#### Instruction
&nbsp;&nbsp;&nbsp;&nbsp;Show all badge level on Steam badge progress page using a clickable button(SCE+ icon)

&nbsp;&nbsp;&nbsp;&nbsp;Wait 3 to 5 second after click a button until badges shown before click another button, or webpage layout may crash

&nbsp;&nbsp;&nbsp;&nbsp;Tested and functional on Firefox with Tampermonkey


#### Version difference(click the link below to install)
&nbsp;&nbsp;&nbsp;&nbsp;[Enhanced Steam Badges.user.js](https://github.com/PMisRIGHT/Enhanced-Steam-Badges/raw/main/Enhanced%20Steam%20Badges.user.js) : Standard version, clean code, no debug and comment

&nbsp;&nbsp;&nbsp;&nbsp;[Enhanced Steam Badges_Notes.user.js](https://github.com/PMisRIGHT/Enhanced-Steam-Badges/raw/main/Enhanced%20Steam%20Badges_Notes.user.js) : The author(me) keep lots of comment for prevent forget code function, and commented some extra function and console code, try it if you are interested

&nbsp;&nbsp;&nbsp;&nbsp;Attention: this two version cover each other when install, no recommended and not necessary to use at same time
